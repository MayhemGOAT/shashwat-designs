# AppleToe Productions

Landing site for **AppleToe** — photography and videography by Shashwat Sagar for underground artists, reels, music videos, and podcasts.

## Features

- Full-bleed hero with interactive film-reel mark
- Scroll reveals, marquees, and hover flash on the work grid
- Direct booking via WhatsApp, Instagram, and email
- Accent tweak (coral / cyan)

## Quick start

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Local development server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |

## Project structure

```
src/
  pages/Home.tsx    # Main landing page
  content.ts        # Brand, services, work, contacts
public/assets/      # Logo and portfolio stills
```

## Stack

React 19 · Vite · TypeScript · React Router

## Note on assets

Logo and portfolio stills under `assets/appletoe-brand/` and `public/assets/appletoe-brand/` include placeholders for development. Swap in final brand and shoot files before a public launch.
